# Intelligent Visual Companion (IVC)

## Overview
Intelligent Visual Companion is an assistive technology project developed by Genetic Code.
The system uses computer vision to recognize human gestures in front of a visually impaired person
and translates those gestures into audio feedback in real time.

## Problem
Visually impaired individuals often miss non-verbal communication such as gestures,
warnings, or directions from people around them.

## Solution
IVC detects common human gestures such as waving, pointing, stop signals, and warnings,
and converts them into meaningful spoken feedback.

## Core Features
- Gesture Recognition
- Direction Awareness
- Audio Feedback
- Real-Time Camera Processing
- Accessibility-Focused Design

## Project Status
This project is currently in prototype and demonstration phase.
